### Code (all in 2.5.0, none of it live for users until Rob pushes)

1. **The update ceiling was about to switch the content channel off.**
   `_updater._MAX_BYTES` was a flat 8 MB chosen when the library was a
   few hundred KB. The library went 2.07 MB -> 5.94 MB in nineteen days
   and is now 6.18 MB. Crossing 8 MB would have failed every download
   silently, leaving every client on its bundled copy. The read limit
   now comes from the manifest's declared `bytes`, which the payload is
   checked against anyway, so it scales on its own; the constant is now
   a 32 MB backstop against a forged manifest. `publish_content.sh`
   reads that backstop from the module, refuses to publish above it, and
   warns from 80% of the 8 MB ceiling that pre-2.5.0 clients still have.
2. **A blocklist that ships as content** (`content/_blocklist.py`).
   Currently empty on purpose. A term firing on the wrong word was the
   one bug class that always cost an AnkiWeb release; it is now a
   content fix. `PhraseMatcher` drops blocked phrases at index time so
   one filter covers all five matchers. It can only suppress - never
   add, retarget or alter - and the tests assert that boundary.
3. **Acronyms got the authoring overlay they never had**
   (`content/_new_acronyms.py`). `pearls/_acronyms` read its dictionary
   out of `library.json` and the build wrote it straight back, so there
   was no way to add one short of hand-editing the artefact. First entry
   is `PCR`: of 33 notes in the live collection, 30 mean amplification
   and 3, all pre-eclampsia cards, mean protein:creatinine ratio. The
   resolver now agrees with all 33 cards' own wording.
4. **Sidebar article list is reachable and stays put.** Dismiss hid the
   whole section, so the only way back was a toolbar button that also
   reloaded the home page - the control that restored the list was the
   control that closed the article. Dismiss is now a collapse, the
   header strip is the toggle, the state persists, and the article the
   reader chose is remembered across restarts.
5. **`search` field on conditions.** Entry names are Australian and
   StatPearls is American, so the name that belongs on the popup is
   sometimes not the name that finds anything. Only the outbound query
   changes.
6. **Security: a config value reached injected JS unencoded.**
   `highlightColor` was interpolated raw into the stylesheet the dock
   highlighter builds inside StatPearls/DrugBank pages. A value ending
   the string literal early ran as script in the page holding those live
   sessions. Now `json.dumps`-encoded *and* validated against a colour
   shape. The remembered sidebar URL is validated the same way,
   fail-closed.
7. `.git` went **372 MB -> 17 MB**. It was 2,114 loose objects that had
   never been packed (`size-pack` was 1.01 MiB); `git gc` did it. Worth
   re-running occasionally - nothing else was wrong.

## Audit coverage - be honest about this

Rob asked for a major audit (future-proofing headline, plus simplicity,
usability, speed, AI tells) and then a minor one (stability, security,
sanity, simplicity). Substantially done, **not exhaustive**.

Covered, with evidence:
- Future-proofing: the size ceiling (above), `SCHEMA` bump semantics now
  documented - adding an optional key must NOT bump, since older clients
  would refuse the whole library - Python 3.9 compatibility (zero 3.10+
  syntax in 156 shipped files), zero unguarded top-level PyQt imports.
- Speed: the dock highlighter runs all 7 vocabularies over a 66 KB
  article in **2.5 ms**, linear in length. No concern.
  **Corrected 2026-09-07 (evening): that figure measures a path the
  add-on does not take.** It timed one `resolve()` sweep over the
  concatenated article. The shipped code calls `highlight_text` once
  per text node - 105 of them on that article - at **16.9 ms**, and up
  to **620 ms** of blocked main thread at the 4000-node cap. The
  conclusion "no concern" does not follow. See the evening checkpoint.
- Security: the JS interpolation class swept file-wide; `highlightColor`
  was the only unencoded site and is fixed, with a guard test that walks
  interpolation sites (proven to fail when the fix is reverted).
