# Curriculum coverage - 2026-09-07

First measurement of the library against Year 4 curriculum frameworks
rather than against one collection of flashcards. Derived counts only;
no curriculum text is reproduced here or anywhere in this repository.

Taken at 2,320 rich summaries.

| module | framework items | genuinely missing | coverage |
|---|---:|---:|---:|
| Medicine | 597 | 81 | 85% |
| Obstetrics & Gynaecology | 253 | 31 | 85% |
| Paediatrics | 238 | 54 | 74% |
| Psychiatry | 192 | 50 | 70% |
| **total** | **1280** | **216** | **81%** of 1153 scoreable |

"Scoreable" excludes items classified as learning outcomes or
communication skills - things with no entity a popup could attach to.

## Why the automated number is not the answer

Three figures came out of the same library on the same day: 35% from the
first automated check, 47% after fixing it, and 81% after judging each
apparent gap on meaning rather than string.

The residual is wording. The curriculum says "Spontaneous abortion"
where the library says "Miscarriage", "Bacterial meningitis" where it
says "Meningitis", "Acute CVA" where it says "Stroke". No string test
closes that, because the question is whether two names mean the same
thing.

So the automated pass produces a *candidate* list and nothing more. Any
statement about coverage has to come from triaging that list.

Two faults in the check itself, both of which had inflated the gap:

- It compared string lengths, requiring a match to be at least 60% as
  long as the framework item. That discarded every correct
  modifier-plus-entity pair. It compares head nouns now.
- The duplicate check never scanned the 430-key acronym channel, several
  of whose entries carry real teaching summaries. It does now, matching
  both the key and its expansions.

## What the 216 gaps look like

They cluster rather than scatter, which makes them cheap to work:

- **Obstetrics & Gynaecology** - examinations and procedures (vaginal,
  speculum, bimanual, colposcopy, diagnostic laparoscopy), and
  stillbirth, which twelve entries reference and none defines.
- **Paediatrics** - presentations rather than diseases. Eleven
  approach-to entries whose constituent diagnoses all already exist.
- **Medicine** - presentation entries (lymphadenopathy, dysphagia,
  haematuria, heart murmur) and six system-examination entries, filling
  a genre the library already has in Mental state examination, Newborn
  examination and Slit lamp examination.
- **Psychiatry** - the weakest module. Cognitive behavioural therapy has
  no entry at all despite being named as first-line in 23 existing
  summaries.
