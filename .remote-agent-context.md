- Move optional detail into parenthetical instead of dedicated bullet
- Use abbreviations after first mention (e.g. "acute chest syndrome (ACS)" → "ACS" thereafter)

Script for the insertion:
```python
import textwrap
def fmt(name, text):
    lines = textwrap.wrap(text, width=60, break_long_words=False, break_on_hyphens=False)
    body = "\n".join(f'        "{l} "' for l in lines[:-1]) + f'\n        "{lines[-1]}"'
    return f'    "{name}": (\n{body}\n    ),\n'
```
Insert at the marker `\n}\n\n\n# ═══` (last `}` of `RICH_SUMMARIES` before the next section header).

## 7. What good output looks like

Structure (adapt but keep clinician-facing tone):
```
"Definition sentence with quick framing. Second-sentence context (epidemiology or
key distinction) if useful. Aetiology: risk factors and pathophysiology. Clinical
features: presentation. Ix: workup order and what confirms. Mx: treatment order
with Australian specifics where relevant. Note: pattern-recognition punchline."
```

Bad output:
- Wall of enumerated bullets ("Aetiology: A, B, C, D, E, F, G, H"). Fails px budget and unreadable.
- US-only management ("get Medicare part D approval").
- Uncritical repetition of the diagnosis in the Note when the reader has just read 800 chars about it.
- Padding to hit a target length.

Length target: **1000-1150 characters** is the sweet spot. Under 800 = probably missing useful clinical detail. Over 1200 = will fail char cap.
